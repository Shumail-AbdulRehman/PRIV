# V5 rendered comparison evidence

All app captures use compiled React, the actual backend and migrated disposable
synthetic SQL fixtures. No production/customer records are captured. Public/operator
routes retain real authorization and unavailable-provider states. Capturing a page
does not mean its V5 appearance or complete interaction matrix has been accepted.

Default viewports:1366×900 and390×900, English and Urdu. Full-page captures can be
taller than900px. Drawer/menu captures use the viewport to verify the protected focus
surface. Network-error/loading filenames explicitly identify injected failure/latency
conditions; they are not successful API integration proof.
