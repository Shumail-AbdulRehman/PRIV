# Staff phone app redesign: research and planning

- `planning/brief.md`: the owner's requests, verbatim.
- `planning/intake.md`: questions, accepted recommendations, and what the code showed.
- `planning/repo-survey.md` and `.survey-raw.txt`: the state of the tree on 2026-11-11.
- `planning/dag.md`: every dependency edge and what it consumes.
- `planning/splits.md`: how features became specs, and rejected splits.
- `planning/validator.md` and `validator-raw.txt`: the final validator run.
- `research/stack.md`: library versions, exports and font sources checked.
- `research/models.md`: model ids on the specs.

The plan itself is in `specs-mobile-redesign/`. The design is in `design/mobile-redesign/`.
