# Billing onboarding design review

**Current: revision 2, approved as amended on 2026-11-06. Help/Contact/support/FAQ controls removed.** The first design was rejected on 2026-11-06. It is preserved in v1/v2/v3; those folders are history, not the current proposal.

Open the [revised design](revision-2/v3/index.html) or [revised account screen](revision-2/v3/account.html). Preview URL when the local server is running: `http://127.0.0.1:56789/revision-2/v3/`.

The revision adapts Linear/Notion SaaS patterns to Hygene Ops: a slim setup rail, three clear plan panels, one continuation action and a separate order-summary/Paddle handoff. It retains the actual blue/slate/Inter/Arabic/logo identity. [Research](../../docs/plan-project/billing-onboarding/research/revision-2/saas-patterns.md) records primary sources, public screenshots, what is copied as a layout pattern and what is deliberately not imported.

Expand **Design preview** at the bottom of each revised screen to visit all six screens and preview loading, unavailable, confirmed and uncertain-payment states. Switch language at the top, select a plan and billing interval, continue to payment, open the checkout illustration, preview decline or completion, and use recovery/help. [Revision guide](revision-2/README.md).

These are static local design prototypes. No real account, storage, provider action, card collection or payment occurs. Amounts, dates and usage are illustrative. Implementation must use provider facts and actual Paddle-rendered card fields. Application code and deployments remain unchanged.
